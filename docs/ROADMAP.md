# 路线图 · EOE Club OS

## v0.1 ✅（当前）

目标：跑通最小真实使用路径，然后**停止扩功能**。

验收标准：

1. 打开网站
2. 手机正常使用
3. 查看成长百科
4. 打开 VPE / VPM / VPPR 等官员指南
5. 查看 60 / 80 / 90 分成长路线
6. 查看本周例会
7. 一键打开腾讯文档 / 投票 / 其他外部工具
8. 完成一次会后记录
9. 记录嘉宾来源
10. 查看基础运营数据

## v0.1 → v0.2 之间：真实使用 4 周

在开发 v0.2 之前，先让官员团队真实用 3-4 场例会，观察：

- 本周例会页面是否真的替代了「群里翻链接」？谁在更新？多久更新一次？
- 会后记录能否在 1 分钟内完成？哪个字段大家总是空着？
- 成长百科哪几页被看得最多？哪些内容需要 EOE 自己的实践笔记？
- 官员工作台的 checklist 有没有人用？

## v0.2 候选方向（未确认，需要讨论后再做）

按「真实摩擦」排序，而不是按「功能酷不酷」：

1. **内容补全**：把真实链接（腾讯文档、投票模板、海报模板）和 EOE 实践笔记填进 `content/`；研究 Agent 产出的资料放进 `content/notes/`。
2. **部署上线**：Vercel + Supabase + 自定义域名，设置 `EOE_WRITE_CODE`。
3. **会后记录的小改进**：例如编辑已有记录（目前只能删除重记）。
4. **例会历史**：每周保存一份例会快照，而不是只保留「本周」。
5. **看板**：按月汇总、嘉宾来源随时间变化（等数据量 > 10 场再说）。

不确定要不要做的，先写进 [BACKLOG.md](BACKLOG.md)。
