# 接入方案：EOE 成长百科 → EOE Club OS（第一版）

> 2026-10-07 · 一页以内 · 写完即开始实现

## 现状

- 系统：Next.js 16 + TypeScript + Tailwind；内容在 `content/`（Markdown / YAML），页面服务端读取文件渲染；无登录。
- 成长百科：本次收到的是**合并版全文**（聊天里粘贴）。已用脚本按一级标题拆回分文件，放在 `docs/eoe-growth-wiki/`，正文逐行与粘贴版一致（只去掉了合并时加的 `---` 分隔线）：
  - `content/eoe-context.md`、`content/handover.md`
  - `content/officers/{vpe,vpm,vppr}.md`、`content/roles/{toastmaster,general-evaluator,meeting-manager}.md`
  - `research/SOURCES.md`
- **没收到**：`docs/eoe-growth-wiki/CLAUDE.md`（内容规则）、各文件的 YAML frontmatter、CHANGELOG。压缩包里的分文件版到了以后直接覆盖即可，解析器同时兼容有 / 无 frontmatter。

## 怎么接入

1. **唯一来源**：成长百科页面只读 `docs/eoe-growth-wiki/`。v0.1 我手写的 `content/officers|roles|notes|_templates` 草稿**删除**，避免两份内容、也避免被误认为 EOE 经验。
2. **解析**（`src/lib/content.ts` 重写）：按 `## N. 标题` 切出 0–9 节，按 `###` 切小节；标题从一级标题解析（`教育副主席 VPE（…）` → 中文名 / 英文名）；frontmatter 有就优先用。官员 / 会议角色由所在目录决定。
3. **来源表**（`src/lib/sources.ts`）：解析 `research/SOURCES.md` 的表格和「核心观点」段落 → 编号 → 标题 / 作者 / 链接 / 时间 / 阅读程度。
4. **可信度标记**（remark 插件，只改显示、不改文字）：
   - `【EOE 已确认 日期】`、`（EOE 已确认）` → 绿色徽章，所在条目整行高亮；
   - `[V1]` 等编号 → 可点的小标签，点开底部弹出来源卡片（「仅读到摘要」的来源单独标出），可跳到资料总表；
   - `（推论…）` → 琥珀色虚线标签；
   - `<!-- TODO(EOE): … -->` → 灰色「待 EOE 确认 / 可选补充」小标签。
5. **勾选清单**：第 8 节和交接清单的 `- [ ]` 变成可勾选。系统没有登录，所以**按设备保存**（浏览器 localStorage），不做「按用户」。
6. **新页面**：`/wiki/handover`（官员交接）、`/wiki/context`（EOE 现状）、`/wiki/sources`（资料总表）。交接指南入口放在：首页、成长百科首页顶部、工作台首页顶部、每个官员页和官员工作台。
7. **扩展**：往 `docs/eoe-growth-wiki/content/officers|roles/` 加一个 `.md` 就会自动出现；图标 / 排序在 `content/wiki-display.yaml`（可选，缺省有默认值）。

## 不做

## 已发现的格式问题（正文没改，只记录）

1. **缺文件**：合并版里没有 `CLAUDE.md`（内容规则）、各文件的 frontmatter、`CHANGELOG`（交接清单最后一项提到它）。总点评文件名原文没写，暂定 `roles/general-evaluator.md`。
2. **「EOE 已确认」写法不统一**（会议经理页）：第 3 节末尾和第 8 节第一条写的是 `（EOE 已确认）`（没日期）；第 4 节表格「依据」列写 `EOE` / `EOE + [MM1]`；第 5 节 90 分写 `（EOE）`；主持人页 9.1 第 6 条写 `（EOE 分工 + [T1] 的"主线"思路）`。系统把 `（EOE 已确认）` 显示成不带日期的绿色徽章，其余几种按普通文字显示。建议统一成 `【EOE 已确认 2026-10-06】`，或约定一个「EOE 定义」标记。
3. **会议经理第 0 节**：`【EOE 已确认】` 只写在段首，下面四条列表属于同一条确认；整节已用绿色底显示，不影响阅读。
4. **段落归属**：会员副主席第 6 节的「**补充反面案例**」、会议经理第 6 节的「**补充参考**」写在最后一个 `###` 下面，网页上会显示在「前人经验 03」卡片里。如果它们不属于经验 03，建议单独加一个 `###` 小标题。
5. **SOURCES.md**：官方资料表里 O6 排在 O5 前面；MM3、MM4（借用）没有链接，也没有被任何角色页引用。编号带后缀（`C1（补充）`）系统能识别。
6. **只读到摘要的来源**：O1–O6、C1、M4、M5、P4、P5、T3、MM1、MM2、TT2–TT4、X2、X3 的「阅读程度」是摘要；网页上这些来源标签用虚线框，弹出卡片里也会提示「引用要谨慎」。
7. **内容一致性（非格式）**：主持人页开头注释说"如果 EOE 设有会议经理…由 EOE 自行确认"，但会议经理第 0 节和主持人 9.2 已经确认了分工，这句注释可能已过时。
