# 公关副主席 VPPR（Vice President Public Relations）

> 来源编号见 [research/SOURCES.md](../../research/SOURCES.md)。标注「推论」的是综合多方资料的判断，不是某位作者原话。

## 1. 一句话理解

VPPR 负责"让对的人知道我们存在，并且愿意来看看"：对外让潜在会员找得到、看得懂、想来；对内让会员知道俱乐部在发生什么、谁值得被庆祝。

## 2. 为什么值得做

**能练到什么**：市场推广、社交媒体运营、媒体关系、品牌管理、内容策划、与社区沟通 [O3]。

**能获得什么存在感**：
- 这是最容易"带出俱乐部"的技能。一位前 VPPR 说，学会做宣传日历、写新闻稿、接受媒体采访，后来直接帮他推广自己的业务，并开启了演讲事业 [P1]。
- 另一位从零开始做 VPPR 的会员，因为这段经历学会了内容创作，后来成为职业创作者 [P2]。
- 没有营销背景也能做——有人形容这像一次带薪以外的实习 [P4]。

## 3. 官方职责（简版）

据 TI 官方 VPPR 职责页 [O2] 及 District 106 培训讲义 [O3]：
- 保护 Toastmasters 品牌
- 制定 PR 计划：评估过去的做法、设目标、定预算、做宣传日历、选择渠道
- 维护俱乐部社交媒体和网站，写新闻稿、做宣传物料
- 确保 Club Central 中的联系方式和会议信息准确（这决定了别人在官网"Find a Club"能不能找到你）
- 与其他官员沟通 PR 计划，跟踪目标进度
- 持续关注 TI 官方资讯

## 4. 会前 / 会中 / 会后

| 阶段 | 要做的事 | 依据 |
|---|---|---|
| **上任第一周** | 检查官网和社交账号；找前任和会长了解俱乐部历史；拿到所有账号权限 | [P5][P1] |
| **学期初** | 做一份年度/季度宣传日历（例会、比赛、周年、特别活动） | [P1][P3] |

## 5. 60 / 80 / 90 分模型

> 非官方评分（v1，已根据前人经验评估），帮助 EOE 会员理解"我要做到什么程度"。

### 60 分：及格
- 公开信息准确：会议时间、地点、联系方式都是对的，访客不会扑空 [O2][P1]
- 每次例会前有预告，会后有简单回顾 [P1]
- 选定 1–2 个平台，保持持续更新，而不是到处开账号 [P1]
- 使用的素材不违反品牌规范 [O2][P1]

### 80 分：靠谱的人
- 有宣传日历，提前几周为活动预热，而不是临时赶工 [P1][P3]
- 内容围绕"会员的蜕变故事"和"你能得到什么"，而不只是"本周议程" [P1][P3]
- 与 VPM 配合：开放日、访客邀请素材、会员庆祝都一起规划 [P1][M2]
- 把会员成就做成内容，让会员被看见（这同时是留人的工具）[M2]
- 看数据调整，目标定得小而可实现 [P2]

### 90 分：真正优秀
- 建立 PR 小组，让想练写作、设计、摄影的会员参与，把 PR 变成他们的成长机会 [P2]
- 俱乐部定位清晰：我们是谁、服务谁、提供什么体验——所有内容自然一致 [P3]
- 能跑完一个有目标、有节奏、有复盘的完整 campaign（例如开放日或招募活动）[P3]
- 提前培养接班人，留下交接文档和模板库 [P1]

## 6. 前人的三条经验

### 前人经验 01 —— 你的会员就是最好的素材
- **谁**：Ankur Yadav, DTM（印度 Gurgaon Orators Toastmasters VPPR），收录于 Diane Windingland 的文章 [P1]
- **核心观点**：一个二三十人的俱乐部，就有二三十个蜕变故事可以讲。宣传用的平台要跟着目标人群走——他们的潜在会员是 20–30 岁的年轻人，所以主要用 Instagram。同一篇文章也建议：与其所有平台都开，不如选一两个持续发；图片比文字更吸引人。
- **为什么有价值**：解决了新手 VPPR 最大的困惑——"到底发什么？"
- **EOE 可以怎么用**：建立一个"会员故事库"，每月做一位会员的小故事（征得同意）。先想清楚 EOE 的潜在会员在新加坡主要用哪些平台。
- **来源**：[P1]

### 前人经验 02 —— 用内容支柱和日历，让宣传可持续；把 PR 变成团队的事
- **谁**：Gia Abao，前 Metro Manila Toastmasters VPPR，零经验上任，后成为拥有约 200 万粉丝的内容创作者 [P2]
- **核心观点**：先定 3 个"内容支柱"（例如演讲技巧、领导力、个人成长），再按周排内容日历；看平台数据调整方向；目标要小而具体（例如每月新增 10 个关注者，而不是三个月 1000 个）；建立 PR 小组——她发现很多会员想练写作，于是请他们来写初稿。
- **为什么有价值**：VPPR 最常见的失败是"一开始很积极，三个月后停更"。支柱 + 日历 + 小组是防止倦怠的系统。
- **EOE 可以怎么用**：这和 EOE 现有的内容工作流思路相通，可以给 EOE 定 3 个内容支柱，并邀请想练华文写作的会员加入 PR 小组——对正在学华文的会员来说，这本身就是练习机会（推论）。
- **来源**：[P2]

### 前人经验 03 —— 别想太多，先开始，再持续改进
- **谁**：Clementine Flack（英国 The Speakers of Croydon Club 2025–26 VPPR）、Sharookh Daroowala, DTM（加拿大 Quay Speakers 前 VPPR）、Rose Kirland, DTM，收录于 Jennifer L. Blanck 的文章 [P3]
- **核心观点**：Flack 认为 PR 不应是一次性动作，要持续、有计划、不断改进；她为 Speechcraft 跑了 8 周宣传，每周 2–3 帖，最终 8 人报名（目标 10 人），整个执委团队也因此更投入 PR。Daroowala 主张"卖结果"——用有目的的故事打动人，而不是罗列活动内容。Kirland 认为，当俱乐部清楚自己是谁、服务谁、提供什么体验，PR 就会变得自然真实。
- **为什么有价值**：给出了从"完美主义停滞"到"持续行动"的心态转变，以及一个有真实数字的小型案例。
- **EOE 可以怎么用**：EOE 已有明确的文化方向（松弛、自由、有趣、连接、温情、真实表达），可以直接作为内容基调的"定位说明书"。
- **来源**：[P3]

## 7. 踩坑指南

**第一次做最容易犯的错**
- 所有平台都开账号，结果每个都更新不了 [P1]
- 公开信息过期（时间地点不对），访客白跑一趟 [P1]
- 只发"本周议程"，不讲人和故事 [P1][P3]
- 一个人包办所有内容，几个月后停更 [P2]

**看起来重要、其实没那么重要的**
- 追求每一张图都很精美——持续、及时比完美更重要 [P3]
- 在大城市主攻传统媒体：文章指出，大都市的俱乐部很难获得媒体报道，小社区才更容易 [P1]

**投入多、收益低的**
- 定过高的增长目标然后受挫——小而可达成的目标更能坚持 [P2]

**只有做过才知道的**
- 账号和密码的交接是大问题：要早点写交接文档 [P1]
- 会员被别人公开表扬，比自己发帖更有感觉；认可内容同时是留人的工具 [M2]
- 前任可能很久没更新——别焦虑，先发几张例会照片让账号"动起来" [P5]

## 8. 如果你明天第一次做 VPPR

只记住这 4 件事：

- [ ] **先检查公开信息是否准确**：时间、地点、联系方式、群链接。[O2][P1]
- [ ] **只选 1–2 个平台。** 每次例会前一条预告、会后一条回顾，先坚持一个月。[P1]
- [ ] **讲人，不只讲活动。** 每次至少拍一张有人、有笑容的照片。[P1][P3]
- [ ] **找一个帮手。** 请一位会员帮你拍照或写文案，他会成为你的接班人。[P1][P2]

## 9. 实践做法与 EOE 笔记

### 9.1 头马俱乐部的实践做法（来自前人亲身经验，EOE 默认采用）

1. **定 3 个内容支柱**，再按周排内容日历，避免"想到才发"。[P2]
2. **会员故事系列**：每个会员都有自己的蜕变故事，是最好的素材（发布前征得本人同意）。[P1][P2][P3]
3. **固定节奏**：例会前一条预告、会后一条回顾，先保证持续。[P1]
4. **建一个小 PR 小组**：把想练写作、设计、摄影的会员拉进来，PR 变成他们的成长机会，也就不会只靠一个人。[P2]
5. **每季看一次数据**：哪类内容反响好就多做；目标定小而具体。[P2]
6. **每学期核对一次公开信息**：时间、地点、联系方式、报名入口。[P1]
7. **账号清单 + 交接**：所有平台账号、密码保管方式、发布流程写进交接文档，早点带一位接班人一起做。[P1][X1]
