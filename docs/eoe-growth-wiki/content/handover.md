# 官员交接指南（所有官员通用）

> EOE 建设成长百科的核心目的，是让经验跨届留存。这一页整理头马前人关于"交接"的亲身经验，适用于所有官员角色。

## 为什么交接这么重要

- 一位前任俱乐部会长回忆：任期快结束时，他心里想的是"要是一开始就知道这一年学到的东西就好了"。[X2]
- 一位做过多次官员的会员估计：一个角色往往要半年左右才真正上手，而上手时任期也差不多结束了。[X1]
- 有前人指出，迟迟不做接班规划，可能正是俱乐部每年都找不到人当官员的原因之一。[X1]

## 前人的做法

1. **卸任前一对一交接**：除了参加官方培训，每位官员和自己的前任单独过一遍职责、心得、资料和问题。一位资深会员认为，没有比"由正在做这件事的人告诉你"更好的培训。[X1]
2. **任期内记工作日志**：很多官员会把一年的工作记下来，让接班人看到真实的样子；同时列出本角色的最佳做法和关键时间点（例如续费日期、比赛时间）。[X1]
3. **"第二梯队"助理制**：提前找潜在接班人，以助理身份跟着做一年。[X1]
4. **别一次塞太多**：交接时不要把所有信息一股脑倒给对方，挑最重要的。[X1]
5. **讲真实的困难**：除了讲成绩，也坦白分享担心、压力和倦怠的时刻，帮接班人提前预判；同时提醒对方不要用不可能的标准要求自己。[X3]
6. **渐进式交接**：交接应该是逐步、充分分享信息的过程，理想状态是真正交接那天几乎"没什么事"。[X2]
