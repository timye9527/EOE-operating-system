# 主持人 Toastmaster（Toastmaster of the Day / Evening）

> 来源编号见 [research/SOURCES.md](../../research/SOURCES.md)。标注「推论」的是综合多方资料的判断，不是某位作者原话。
> 注：如果 EOE 设有「会议经理」，主持人和会议经理在会前协调上有重叠，分工请见 [meeting-manager.md](meeting-manager.md) 并由 EOE 自行确认。

## 1. 一句话理解

主持人是整场会议的"导演 + 司仪"：会前把人和流程准备好，会上定调、串场、控时间，把舞台交给每一位上台的人，再稳稳接回来。

## 2. 为什么值得做

**能练到什么**：组织、时间管理、公众表达 [O5]；还有临场应变、串场与过渡、照顾全场情绪。

**能获得什么存在感**：
- 这可能是最重要的会议角色：其他角色主要服务于自己的学习，主持人要对整场会议的成功负责 [T1]。
- 主持人有自信、有节奏，其他上台的人也会表现得更好——你是全场的"稳定器" [T1]。
- 这是一个在安全环境里练"管理一场会议"的机会，能直接迁移到工作中 [T1]。

## 3. 官方职责（简版）

据 TI 官方会议角色页 [O5]：
- 从 VPE 拿到会议议程
- 与总点评（GE）配合，确保所有角色知道自己的职责
- 会上介绍讲者，包括题目、项目名称、项目目标、时长等
- 确保环节之间、讲者之间过渡顺畅

官方也提到：通常要等会员比较熟悉俱乐部流程之后，才会安排这个角色 [O5]。

## 4. 会前 / 会中 / 会后

| 阶段 | 要做的事 | 依据 |
|---|---|---|
| **会前 1 周** | 定好主题并通知所有角色（方便讲者、即兴主持融入主题） | [T2] |
| **会前 1 周** | 发提醒消息，确认出席；向讲者收集讲题和一段简短介绍 | [T2] |
| **会前 1 周** | 给讲者配点评人：尽量水平相近；破冰演讲配有经验的点评人 | [T2] |
| **会前** | 准备开场白、讲者介绍、环节之间的过渡语（包括应对冷场的备用话） | [T3] |
| **会前** | 和导师或有经验的会员过一遍议程 | [T2] |
| **当天提前到** | 确认所有人到场；核对每个人名字的读音 | [T2][T3] |
| **会中** | 开场简短；介绍讲者（结构化，30–60 秒）；带头鼓掌；盯时间；熟悉其他角色，必要时当场补位或纠正 | [T2][T3] |
| **会后** | 向总点评和有经验的会员要反馈，记下下次可改进的地方 | [T1] |

## 5. 60 / 80 / 90 分模型

> 非官方评分（v1，已根据前人经验评估），帮助 EOE 会员理解"我要做到什么程度"。

### 60 分：及格
- 会前确认每个角色都有人、议程正确 [O5][T1]
- 每位讲者都被清楚介绍：名字、题目、项目、时长 [O5][T3]
- 会议大致按时进行，不严重超时 [T2]
- 名字没读错 [T2]

### 80 分：靠谱的人
- 提前一周定主题、发提醒、收集讲者资料，让大家有时间准备 [T2]
- 讲者和点评人的配对是用心安排的，新人得到好的点评 [T2]
- 准备好过渡语，环节衔接自然，没有尴尬空白 [T3]
- 开场白短而有温度，把时间留给来宾和讲者 [T2]
- 带动掌声和气氛，让上台的人感到被支持 [T2][T1]

### 90 分：真正优秀
- 让整场会议有一条清晰的主线（主题贯穿即兴、演讲和总结）[T1][T2]
- 遇到临时缺席、超时等意外，能冷静调整，大多数人甚至察觉不到 [T1][MM2]
- 主持风格稳定而有感染力，让其他角色表现得更好 [T1]
- 会后把流程中发现的问题告诉 VPE / 会议经理，改进下一次（推论，结合 [T1] 的"会议经理"定位）

## 6. 前人的三条经验

### 前人经验 01 —— 你不只是串词的人，你是这场会议的经理
- **谁**：Bill Brown, DTM，演讲教练，*Toastmaster* 杂志长期专栏作者 [T1]
- **核心观点**：大多数角色是"到场就能做"，主持人不一样——你要像负责一场工作会议那样：排议程、确认人员、补漏洞，开会时接管全场。同时你是司仪：定调，把接力棒交给讲者，再接回来。即使讲者表现平平，主持人的节奏也能让全场保持活力。如果现在还不够自信，就观察优秀主持人，并先从即兴主持、总点评这些"小型司仪"角色练起。
- **为什么有价值**：帮新人理解"为什么主持人要提前一周开始准备"，而不是当天拿着稿子念。
- **EOE 可以怎么用**：在 EOE 的角色阶梯里，可以把"即兴主持 / 总点评"作为做主持人之前的推荐练习。
- **来源**：[T1]

### 前人经验 02 —— 魔鬼在细节：名字读音、开场长度、点评配对
- **谁**：Felicity Barber，旧金山 Rhino Business Toastmasters 会员，职业撰稿人，第一次当主持人后写下的复盘 [T2]
- **核心观点**：她的十条里，最有"做过才知道"味道的是：提前到场核对每个人名字的读音，哪怕你以为自己知道；开场白要短，因为来宾介绍往往比预期更花时间；给破冰演讲的新人配一位有经验的点评人，好的点评会让他们愿意继续讲；熟悉其他角色，计时官或哼哈官出错时你能马上补救；会前和导师打电话过一遍议程，比发消息更容易发现问题。
- **为什么有价值**：这些都是官方职责说明里不会写、但直接影响体验的细节。
- **EOE 可以怎么用**：华文名字的读音（以及中英文名的称呼方式）在 EOE 场景里同样重要，可以写进主持人会前清单。
- **来源**：[T2]

### 前人经验 03 —— 讲者介绍要有固定结构，过渡语要提前备好
- **谁**：Katong Toastmasters Club（新加坡）的 TME 角色指南 [T3]
- **核心观点**：讲者介绍控制在 30–60 秒，按固定要素组织（例如项目、目标、计时规则等）；提前准备好环节之间的过渡语——可能用不上，但一旦冷场就能救场；当天早到。
- **为什么有价值**：新加坡本地俱乐部的做法，场景与 EOE 接近；"固定结构"能大幅降低新手主持的焦虑。
- **EOE 可以怎么用**：EOE 可以制定自己的"讲者介绍模板"（华文版），让每一位主持人都有统一的起点。
- **来源**：[T3]（仅读到摘要，结构细节需回原文核对）

## 7. 踩坑指南

**第一次做最容易犯的错**
- 当天才开始准备，结果角色有空缺、讲者资料不全 [T1][T2]
- 开场白太长，挤压了后面的时间 [T2]
- 读错别人的名字 [T2]
- 只念稿，没有准备过渡语，一冷场就慌 [T3]

**看起来重要、其实没那么重要的**
- 追求华丽的开场和台词——主持人的价值在于让别人发光、让会议顺畅，不在于自己表现 [T1]（推论）

**投入多、收益低的**
- 花大量时间写逐字稿，却没有花时间确认人员和时间安排（推论，基于 [T1][T2] 对会前协调的强调）

**只有做过才知道的**
- 来宾介绍几乎总是比预想更久 [T2]
- 你的情绪会传染全场：你稳，大家就稳 [T1]
- 熟悉每一个角色，关键时刻你可能要替别人补位 [T2]

## 8. 如果你明天第一次做主持人

只记住这 5 件事：

- [ ] **今天就发一条消息给所有角色**：确认出席，问讲者要题目和一句话介绍。[T2]
- [ ] **准备 3 样东西**：30 秒开场白、每位讲者的介绍、3 句万能过渡语。[T3]
- [ ] **提前 15 分钟到场**，把每个人的名字读音确认一遍。[T2]
- [ ] **开场要短，时间要盯紧。** 把舞台留给别人。[T2]
- [ ] **你是这场会议的经理。** 有人缺席不要慌，先找人补位，其他人会帮你。[T1][MM2]

## 9. 实践做法与 EOE 笔记

### 9.1 头马俱乐部的实践做法（来自前人亲身经验，EOE 默认采用）

1. **接龙报名后，会前一周发提醒**：确认出席，向讲者收集题目和一句话简介。[T2]
2. **讲者介绍用固定结构**：30–60 秒，包含名字、题目、项目、时长。[T3][O5]
3. **准备 3 句备用过渡语**：冷场时救场用。[T3]
4. **提前到场，核对名字读音**：华文名、英文名怎么称呼，都先问清楚。[T2]
5. **开场要短**：来宾介绍往往比预期花时间。[T2]
6. **与会议经理对齐主题**：在 EOE，主题由会议经理定，主持人负责把主题串进整场会议。（EOE 分工 + [T1] 的"主线"思路）
7. **心里有后备**：有人临时缺席时，知道可以找谁补位。[MM2]
