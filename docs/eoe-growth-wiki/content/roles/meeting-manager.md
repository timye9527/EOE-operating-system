# 会议经理 Meeting Manager

> 来源编号见 [research/SOURCES.md](../../research/SOURCES.md)。标注「推论」的是综合多方资料的判断，不是某位作者原话。

> **关于这个角色**：「会议经理」不是头马官方的会议角色名称，各中文俱乐部定义不同。**在 EOE，会议经理 = 定主题 + 兼任即兴主持（Table Topicsmaster）+ 策划本次会议。** 所以本页的外部经验主要来自头马官方体系里的**即兴主持（Topicsmaster）**和会议筹备相关资料。

## 0. EOE 的会议经理（已确认）

【EOE 已确认】在 EOE，会议经理负责：
- **定本次会议的主题**；
- **兼任即兴环节的主持**，自己推动，把即兴环节带起来——因此要承担一定的策划工作；
- 可选：**提前邀约嘉宾，安排工作坊**等内容。
- 会议当天的**主持人（Toastmaster）另有其人**，由会员通过会议角色接龙报名。

EOE 的整体做法比较简洁。凡外部资料与本节冲突，以本节为准。

## 1. 一句话理解

会议经理是一次例会的"策划人 + 即兴环节主持"：定一个主题，设计即兴题目，在会上把即兴环节带起来，让尽量多的人有机会开口。

## 2. 为什么值得做

**能练到什么**：策划与组织、时间管理、引导与控场 [TT1]；还有把一个主题变成一场有意思的会议的创意能力 [TT2]。

**能获得什么存在感**：
- 你决定了这次会议"是什么味道"。主题和即兴，是会员和访客最直接感受到的部分。
- 即兴主持的真正价值，是让更多人有机会开口——包括那些当天没有角色的人 [TT1]。你在为别人创造舞台。
- 好的即兴题目能让大家发现彼此不知道的一面 [TT2]，这正是"连接"的时刻。

## 3. 官方职责（参照头马即兴主持 Topicsmaster）

头马官方没有"会议经理"，最接近的是即兴主持（Topicsmaster）[TT4]：
- 会前选好题目，题目要能让人表达观点
- 让当天没有讲话角色的会员也有机会发言
- 不给两个人问同一个问题（除非刻意要正反观点）
- 如俱乐部有"最佳即兴"奖，组织投票

EOE 额外职责：定主题；可选邀约工作坊。（EOE 已确认）

## 4. 会前 / 会中 / 会后

| 阶段 | 要做的事 | 依据 |
|---|---|---|
| **会前 1–2 周** | 定主题；告诉主持人、VPPR（方便宣传和串场） | EOE + [MM1] |
| **会前 1 周** | 如有工作坊或嘉宾，确认时间和内容 | EOE |
| **会前** | 准备即兴题目：数量 = 通常发言人数 + 4–5 道备用；题目简单、贴主题；按好坏排序 | [TT1] |
| **会前** | 想好一个有创意的形式（节日、道具、角色扮演……），别在前一晚随便搜一份题单 | [TT2] |
| **会议开始后** | 列出到场名单，分组：没角色的 → 小角色 → 大角色 → 访客 | [TT1] |
| **即兴环节** | 开场简短说明规则和时长；先点没角色、不常发言的人；访客不放在第一、第二个；每题之间过渡要短；留意主持人的收尾信号 | [TT1][TT3] |
| **会后** | 把用过的好题目存进题库，留给下一位（推论，服务于 EOE 的经验留存目标） | [X1] |

## 5. 60 / 80 / 90 分模型

> 非官方评分（v1，已根据前人经验评估），帮助 EOE 会员理解"我要做到什么程度"。

### 60 分：及格
- 会前定好主题，并告诉主持人 [MM1]
- 准备的题目够用（发言人数 + 几道备用）[TT1]
- 即兴环节按时结束，配合主持人的时间信号 [TT1]

### 80 分：靠谱的人
- 题目简单、容易接，让人专注于"怎么说"而不是"说什么" [TT1]
- 有意识地先点没有角色、不常发言的人；访客先看别人示范再邀请 [TT1]
- 自己说得少：开场简短，过渡更短，把舞台留给会员 [TT3]
- 主题提前给 VPPR 做宣传，信息准确 [MM1]
- 心里有后备：有人缺席时知道怎么调整 [MM2]

### 90 分：真正优秀
- 用有创意的形式让即兴变得好玩，大家愿意参加 [TT2]
- 主题贯穿整场会议，主持、即兴、演讲有一条主线 [T1][T2]
- 视情况提前邀约工作坊或嘉宾，让会议有额外价值（EOE）
- 把主题和题目存进题库，下一位会议经理不用从零开始（推论，结合 [X1]）

## 6. 前人的三条经验

### 前人经验 01 —— 即兴主持不是给你自己讲的，是给别人机会讲
- **谁**：Bill Brown, DTM，演讲教练，*Toastmaster* 杂志长期专栏作者 [TT1]
- **核心观点**：他入会时学到的原则是：每个人都应该有机会在会上开口。所以他每次都多准备 4–5 道题；会议开始后把到场的人分成"没角色、小角色、大角色、访客"四栏，先点没角色的人；忍住先点"讲得最好的人"的冲动，因为他们最不需要练习；访客不放在第一、第二个。他还分享了自己的转变：早期他喜欢出很难、很天马行空的题，结果发现大家都绕开题目去讲别的，于是改成出简单的题，让讲者专注于组织和表达。
- **为什么有价值**：一套可以直接照做的点人顺序，加上一个真实的"出题踩坑"。
- **EOE 可以怎么用**：EOE 是小俱乐部，更要保证每个人都轮得到；"四栏点人法"可以直接写进会议经理清单。
- **来源**：[TT1]

### 前人经验 02 —— 别在前一晚随便搜一份题单
- **谁**：Silvana Clark，美国 Bellingham Toastmasters Club 60 会员 [TT2]
- **核心观点**：很多人报名即兴主持时想着要好好设计，结果前一晚才匆忙上网搜一份题单。她建议给即兴加点创意：线上会议就利用大家在家的环境；节日主题；用道具（例如给书包上假封面）；虚构法律让大家说理由。这样做，你会发现会员身上你从来不知道的一面。
- **为什么有价值**：主题和形式决定了会议"好不好玩"，这和 EOE 松弛、有趣的风格一致。
- **EOE 可以怎么用**：建一个"EOE 即兴形式库"，每位会议经理用过的好形式都加进去。
- **来源**：[TT2]

### 前人经验 03 —— 提前设好后备，尽量不取消会议
- **谁**：James Sultan, DTM，前 Toastmasters 国际理事 [MM2]
- **核心观点**：在角色安排里设"后备"位置，有的俱乐部设一个随时补位的"hot seat"，他建议设两到三个；官员团队提前准备一份"填时间"的活动清单；尽可能不要取消会议。
- **为什么有价值**：小俱乐部最怕临时有人缺席。会议经理作为策划人，手里有后备方案，会议就不会被打乱。
- **EOE 可以怎么用**：会议经理多准备的即兴题目，本身就是最好的"填时间"工具。
- **来源**：[MM2]

**补充参考**：一份中文俱乐部的会议经理 SOP 也强调，要熟悉整个工作流"每个时间点要交付什么"，并把主题、嘉宾资料提前交给公关副主席 [MM1]。

## 7. 踩坑指南

**第一次做最容易犯的错**
- 前一晚才找题目 [TT2]
- 题目太难、太偏，大家只好绕开题目讲别的 [TT1]
- 先点讲得好的人，结果最需要练习的人没轮到 [TT1]
- 自己说太多：长开场、对每个回答都长篇点评 [TT3]

**看起来重要、其实没那么重要的**
- 题目"够不够惊艳"——简单、能让人开口，比惊艳更重要 [TT1]

**投入多、收益低的**
- 每次从零想主题和题目——建题库，下一次就快了（推论）

**只有做过才知道的**
- 访客先看别人怎么答，再被邀请，会更自在 [TT1]
- 主持人会给你收尾信号，记得留意 [TT1]

## 9. 实践做法与 EOE 笔记

### 9.1 头马俱乐部的实践做法（来自前人亲身经验，EOE 默认采用）

1. **题目数量 = 通常发言人数 + 4–5 道**，按好坏排序，好的先用。[TT1]
2. **四栏点人法**：没角色 → 小角色 → 大角色 → 访客（访客不放第一、第二个）。[TT1]
3. **简单的题目优先**；如果大家总绕开题目，说明题目太难。[TT1]
4. **每次至少一个创意形式**（节日、道具、角色扮演、正反方）。[TT2][TT4]
5. **开场简短，过渡更短**，聚光灯给会员。[TT3]
6. **会后把主题和好题目存进题库**，留给下一位。（推论，服务于经验留存）[X1]
