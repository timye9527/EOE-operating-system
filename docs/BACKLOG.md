# Backlog · 第一阶段明确不做

这些功能 **v0.1 有意不做**。原则：已有成熟工具能解决的不重复造轮子；先用起来，等真实摩擦出现再决定。

想把某一项提上来之前，先回答：**它解决了什么真实、反复出现的摩擦？现有工具为什么不够？**

| 功能 | 为什么现在不做 | 现在怎么办 |
|---|---|---|
| 微信接龙 | 微信群接龙已经很好用 | 群里接龙；本周例会页放接龙说明链接 |
| 聊天 | 微信群就是聊天工具 | 微信群 |
| 完整演讲助手 | 已有成熟的演讲助手 / 计时工具 | 工具箱里放链接 |
| AI 演讲点评 | 不是当前运营瓶颈；成本与质量不确定 | — |
| 原生复杂投票 | 腾讯问卷 / 金数据等已能解决 | 投票模板入口 + 例会绑定投票链接 |
| 复杂计时器 | 演讲助手 / 手机秒表即可 | 工具箱、Timer 角色指南 |
| 会员积分 | 容易变成负担，偏离「成长」本身 | — |
| 勋章 | 同上 | — |
| 商城 | 与核心目标无关 | — |
| 支付 | 涉及资金合规；量小 | 财务按现有方式收款 |
| 复杂 CRM | 20 人规模不需要；涉及个人信息 | 只统计嘉宾人数与来源；跟进用微信 |
| 自动催办 | 志愿者组织，催办伤感情 | 官员工作台 checklist（只在自己手机上） |
| 多俱乐部 SaaS | EOE 先用好 | — |
| 复杂权限 / 登录 | 内部小工具，链接不外传即可 | 可选的俱乐部口令 `EOE_WRITE_CODE` |
| 社交 Feed | 不是社交产品 | — |
